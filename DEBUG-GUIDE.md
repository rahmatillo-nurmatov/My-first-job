# Руководство по запуску и отладке

## 🚀 Способы запуска проекта

### 1. Через VS Code (Рекомендуется)

#### Запуск и отладка Node.js сервера:
1. Откройте VS Code
2. Перейдите в раздел "Запуск и отладка" (Ctrl+Shift+D)
3. Выберите конфигурацию:
   - **"Launch Node.js Server"** - запуск сервера с отладкой
   - **"Launch Server + Chrome"** - запуск сервера + браузер
   - **"Launch Chrome (Static Files)"** - открытие статических файлов

#### Доступные конфигурации отладки:
- `Launch Node.js Server` - запуск Node.js с отладчиком
- `Launch Chrome (Node.js Server)` - браузер + сервер на порту 3000
- `Launch Chrome (Static Files)` - статические файлы без сервера
- `Attach to Node.js` - подключение к запущенному процессу
- `Launch Server + Chrome` - комбинированный запуск

### 2. Через терминал

#### Запуск Node.js сервера:
```bash
# Обычный запуск
npm start

# Запуск с автоперезагрузкой (для разработки)
npm run dev

# Прямой запуск
node server.js
```

#### Запуск статических файлов:
```bash
# Открыть index.html в браузере
start index.html

# Или использовать Live Server (если установлен)
# Щелкните правой кнопкой на index.html → "Open with Live Server"
```

## 🔧 Решение проблем

### Проблема: "Не могу запустить отладку"

#### Возможные причины и решения:

1. **Порт 3000 занят**
   ```bash
   # Проверить, какой процесс использует порт
   netstat -ano | findstr :3000
   
   # Завершить процесс (замените PID на реальный)
   taskkill /PID [PID] /F
   ```

2. **Неправильная конфигурация launch.json**
   - Убедитесь, что файл `.vscode/launch.json` существует
   - Проверьте правильность портов (3000 для Node.js)

3. **Отсутствуют зависимости**
   ```bash
   npm install
   ```

4. **Проблемы с Node.js**
   ```bash
   # Проверить версию Node.js
   node --version
   
   # Должна быть версия 14 или выше
   ```

### Проблема: "Chrome не открывается"

1. **Проверьте URL в конфигурации**
   - Для сервера: `http://localhost:3000`
   - Для статических файлов: путь к `index.html`

2. **Убедитесь, что сервер запущен**
   - Сначала запустите "Launch Node.js Server"
   - Затем "Launch Chrome (Node.js Server)"

### Проблема: "Ошибки JavaScript в браузере"

1. **Откройте DevTools (F12)**
2. **Проверьте вкладку Console на ошибки**
3. **Убедитесь, что все файлы загружаются:**
   - `public/css/style.css`
   - `public/js/app.js`
   - `public/js/main.js`

## 📁 Структура конфигураций

### .vscode/launch.json
Конфигурации для запуска и отладки:
- Node.js сервер с отладчиком
- Chrome с различными настройками
- Комбинированные запуски

### .vscode/tasks.json
Задачи для автоматизации:
- `npm: start` - запуск сервера
- `npm: dev` - запуск с nodemon
- `Open Static Files` - открытие статических файлов

### .vscode/settings.json
Настройки рабочего пространства:
- Автоподключение отладчика Node.js
- Настройки форматирования
- Ассоциации файлов

## 🎯 Быстрый старт

### Для разработки Node.js приложения:
1. `Ctrl+Shift+D` → "Launch Server + Chrome"
2. Или `F5` → выберите "Launch Node.js Server"

### Для работы со статическими файлами:
1. `Ctrl+Shift+D` → "Launch Chrome (Static Files)"
2. Или щелкните правой кнопкой на `index.html` → "Open with Live Server"

### Для отладки JavaScript:
1. Поставьте точки останова в коде
2. Запустите отладку (`F5`)
3. Используйте DevTools в браузере

## 🔍 Полезные команды

```bash
# Проверить статус сервера
curl http://localhost:3000

# Проверить занятые порты
netstat -ano | findstr :3000

# Перезапустить все процессы Node.js
taskkill /F /IM node.exe

# Установить зависимости
npm install

# Запустить тесты
npm test
```

## 📝 Примечания

- **Порт по умолчанию:** 3000 (Node.js сервер)
- **Статические файлы:** Открываются напрямую в браузере
- **Отладка:** Поддерживается как для Node.js, так и для браузера
- **Автоперезагрузка:** Используйте `npm run dev` для разработки

---

**Если проблемы продолжаются:**
1. Перезапустите VS Code
2. Проверьте, что все файлы сохранены
3. Убедитесь, что Node.js установлен корректно
4. Проверьте права доступа к файлам проекта
